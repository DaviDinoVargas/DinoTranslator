# DinoTranslator

Chamada de vídeo com tradução simultânea em texto, português ⇄ russo, para dois usuários.

## Documentação

- [Planejamento](docs/PLANEJAMENTO.md) — requisitos, arquitetura, fases
- [Identidade visual](docs/DESIGN.md)
- [Segurança](docs/SEGURANCA.md)
- [Fluxo Git](docs/GIT.md)

## Ambiente de desenvolvimento

- Windows 10/11 com WebView2 Runtime
- .NET SDK 9 (10 recomendado)
- Node.js 20+ (camada de mídia em TypeScript)
- Docker (servidor e TURN)
